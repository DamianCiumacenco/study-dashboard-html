# 📚 Student Study Dashboard

A responsive study tracking dashboard built with HTML, CSS and JavaScript.

Built as part of an MH602 Web Development lab at Maynooth University.

---

## ✨ Features
- Personalised welcome message
- Weekly goals display
- Study session counter with add and reset
- Active status badge using CSS pseudo-elements
- Fully responsive — stacks to mobile layout on small screens
- Profile image hidden on mobile

---

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox, CSS Variables, Media Queries, Pseudo-elements)
- Vanilla JavaScript (DOM manipulation, Event Listeners)

---

## 🚀 How to Use
1. Download or clone the repo
2. Open `index.html` in your browser — no server needed
3. Personalise the following:
   - In `script.js` — change `yourName` to your own name
   - In `index.html` — update the profile bio and weekly goals
   - In `index.html` — update the footer with your name

---


## 📁 Project Structure
```
├── index.html      # Main HTML structure
├── style.css       # All styling — variables, layout, responsive
├── script.js       # Welcome message, session counter, goals display
```

---

## 📝 Customisation
| File | What to change |
|------|---------------|
| `script.js` line 2 | Your name for the welcome message |
| `index.html` profile card | Your bio text |
| `index.html` goals list | Your weekly goals |
| `script.js` goals array | Goals shown when "Show Goals" is clicked |
